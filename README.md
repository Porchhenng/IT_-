# Portfolio

Cheng Porchheng's portfolio: a static single-page site with no build step.

```
index.html     the site (EN/JA)
cv.html        print source for the CV PDF
assets/        the CV PDF and the photo, the only files the pages load
DESIGN.md      design system for the current direction
PRODUCT.md     audience, content facts and open decisions
.impeccable/   design critiques, review shots and decisions
```

Open `index.html` in a browser to view it. To rebuild the CV, print `cv.html` to `assets/Cheng_Porchheng_CV.pdf` with headless Chromium (see the note at the foot of `cv.html`) and check it stays one page.
